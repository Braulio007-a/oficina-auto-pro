# Oficina Auto-Pro — website

Single-page website for Oficina Auto-Pro (new front-end kits, wheels, headlights and tail lights for multiple car brands), built with Next.js 16 (App Router), React 19 and TypeScript. Styling uses CSS Modules plus design tokens in `src/app/globals.css`; there are no UI dependencies.

## Run locally

Requires Node.js 20.9+ (tested with Node 24.21 and npm 11.19).

```bash
npm install
npm run dev        # http://localhost:3000
```

Production build:

```bash
npm run build
npm run start      # http://localhost:3000
npm run lint
```

`npm run build` writes a static site to `out/` (`output: "export"`); preview it with any static file server.

## Deploy (GitHub Pages)

Every push to `main` runs `.github/workflows/deploy.yml`, which lints, builds with `BASE_PATH=/<repo-name>` and `SITE_URL=https://<owner>.github.io`, and publishes `out/` to GitHub Pages. Pages must be set to "GitHub Actions" as its source (Settings → Pages).

If the site moves to a custom domain at the root, remove `BASE_PATH` from the workflow and set `SITE_URL` to the new domain.

## Structure

- `src/content/site.ts` — all company content: phone, links, products, brands, steps, gallery. Edit here.
- `src/components/` — header, footer, logo, icons; `sections/` holds each page section.
- `src/assets/photos/` — web-optimised copies of the company photos, generated by `scripts/prepare-images.mjs` from the originals in the parent folder (originals are untouched).
- `src/assets/brand/logo-auto-pro.svg` — vector trace of `logotipo.jpeg`; also used as `src/app/icon.svg`.
